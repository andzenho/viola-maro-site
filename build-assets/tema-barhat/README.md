# Картинки оформления --theme barhat (красное с белым)

Сюда кладутся картинки для `--theme barhat`. Имена файлов строгие: сборщик
ищет именно их (список в `tema_barhat.py`, словарь `SLOTS`). Пока файла нет,
страница собирается без него: на месте значка стоит красная плитка
с линейным знаком, предмета просто нет.

Все PNG — с прозрачным фоном.

| Файл | Что это | Куда встаёт |
|---|---|---|
| `viola.png` | Виола по пояс, вырезана | первый экран, вместо `source/assets/viola-cutout.png` |
| `n1.png` … `n6.png` | объёмные значки шести недель, квадратные | карточки недель и список шести сфер |
| `p1.png` … `p5.png` | значки «каждую неделю вы получаете»: лекция, техники, задания, PDF, аудиоответ | список в блоке программы |
| `podarok.png` | подарочная коробка | четыре карточки подарков |
| `o-18.png` | предмет | нижний правый угол блока «18 техник» |
| `o-programma.png` | предмет | над заголовком «Шесть недель», справа |
| `o-mk.png` | предмет | верхний правый угол блока мастер-класса |
| `o-tarify.png` | предмет | рядом с заголовком «Тарифы» |
| `o-podarki.png` | предмет | над заголовком «Что вы получаете?» |
| `o-final.png` | предмет | верхний правый угол последнего призыва |
| `mk.jpg`, `final.jpg` | фотографии | фоном в красных блоках мастер-класса и финала |
| `hero-desktop.jpg`, `hero-mobile.jpg` | готовая сцена с Виолой | первый экран целиком, вместо вырезки на фоне |
