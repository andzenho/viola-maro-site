# Картинки и шрифт клуба «Опора»

Страницу `/opora/` собирает `opora.py`, стили клуба в `opora.css` рядом.
Картинки кладутся сюда под этими именами (jpg, png или webp), сборка сама
сжимает их в webp. Нет картинки, значит на её месте блок цвета `--panel`.

| Файл | Размер | Где стоит |
|---|---|---|
| `hero-desktop.jpg` | 2400×1350 | первый экран на компьютере, текст слева, Виола справа |
| `hero-mobile.jpg` | 1080×1620 | первый экран на телефоне, текст в верхней трети |
| `viola-portret.jpg` | 1200×1500 | «Кто ведёт клуб» (пока нет, стоит `tema-barhat/viola.png`) |
| `final-desktop.jpg`, `final-mobile.jpg` | 2400×1350, 1080×1620 | фон последнего экрана |
| `hero-fon-desktop.jpg` | 2400×1350 или 1536×1024 | первый экран: стена и диван без Виолы |
| `hero-fon-mobile.jpg` | 2 : 3 | то же, центральная вырезка 2 : 3 из `hero-fon-desktop` |
| `viola-vyrezka.png` | как `hero-fon-desktop`, прозрачный фон | Виола без фона **на том же холсте**, что и фон: ложится поверх 1 в 1 |
| `o-kino.png` | 800×800, прозрачный фон | шаг «Кинотерапия» |
| `o-chashka.png` | 800×800, прозрачный фон | «В день вступления вас уже ждут» |
| `o-pismo.png` | 800×800, прозрачный фон | «Вопросы» |

Сейчас стоят три фото Виолы у изумрудной стены (04.11.2026): `hero-desktop`
— она справа на диване, `hero-mobile` — вырезка 2 : 3 из кадра по центру,
`final-desktop` — тот же кадр по центру целиком, `final-mobile` — вырезка
2 : 3 из первого кадра, `viola-portret` — портрет крупно. Меньше размеров
из таблицы, но для экрана хватает.

Образец вида: лендинг онлайн-школы в стиле отеля «Гранд Будапешт»
(behance.net/gallery/253830093). Текст на фото не кладётся: на первом
и последнем экранах край фото растворяется в фоне --barhat, текст стоит
на нём.

Текст на картинки не запекать: весь текст страницы HTML.

Каллиграфии на странице нет: Артём убрал её 04.11.2026 («плохие шрифты»).
Заголовки Prata прописными, весь остальной текст Golos.
