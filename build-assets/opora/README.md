# Картинки и шрифт клуба «Опора»

Страницу `/opora/` собирает `opora.py`, стили клуба в `opora.css` рядом.
Картинки кладутся сюда под этими именами (jpg, png или webp), сборка сама
сжимает их в webp. Нет картинки, значит на её месте блок цвета `--panel`.

| Файл | Размер | Где стоит |
|---|---|---|
| `hero-desktop.jpg` | 2400×1350 | первый экран на компьютере, текст слева, Виола справа |
| `hero-mobile.jpg` | 1080×1620 | первый экран на телефоне, текст в верхней трети |
| `viola-portret.jpg` | 1200×1500 | «Кто ведёт клуб» (пока нет, стоит `tema-barhat/viola.png`) |
| `final-desktop.jpg`, `final-mobile.jpg` | 2400×1350, 1080×1620 | фон последнего экрана |
| `o-kino.png` | 800×800, прозрачный фон | шаг «Кинотерапия» |
| `o-chashka.png` | 800×800, прозрачный фон | «В день вступления вас уже ждут» |
| `o-pismo.png` | 800×800, прозрачный фон | «Вопросы» |

Сейчас стоят три фото Виолы у изумрудной стены (04.11.2026): `hero-desktop`
— она справа на диване, `hero-mobile` — вырезка 2 : 3 из кадра по центру,
`final-desktop` — тот же кадр по центру целиком, `final-mobile` — вырезка
2 : 3 из первого кадра, `viola-portret` — портрет крупно. Меньше размеров
из таблицы, но для экрана хватает.

Образец вида: лендинг онлайн-школы в стиле отеля «Гранд Будапешт»
(behance.net/gallery/253830093). Текст на фото не кладётся: на первом
и последнем экранах край фото растворяется в фоне --barhat, текст стоит
на нём.

Текст на картинки не запекать: весь текст страницы HTML.

Каллиграфии на странице нет: Артём убрал её 04.11.2026 («плохие шрифты»).
Заголовки Prata прописными, весь остальной текст Golos.

Первый экран (04.11.2026): готовое фото Виолы на диване у изумрудной стены
(`hero-mobile` — вертикальный кадр 1024×1536, `hero-desktop` — широкий кадр 1774×887, Виола справа крупно; оба целиком, без обрезки), без вырезки.
Фото — фон экрана. На компьютере широкий кадр — фон всего экрана, Виола справа,
слева на стене ОПОРА и оффер; на телефоне фото во всю ширину, ОПОРА над Виолой,
кнопка у неё на груди.

Фоны экранов (04.11.2026, как в референсе «Гранд Будапешт» — у каждого экрана
свой материал отеля), подключаются в `sec(..., fon=...)`, затемнение в `opora.css`:

| Файл | Экраны |
|---|---|
| `fon-barhat.jpg` | «Что изменится», «Почему это удобно» |
| `fon-bumaga.jpg` | «Отзывы», «Вопросы» (плиткой, бумага цвета слоновой кости) |
| `fon-derevo.jpg` | «Как проходит месяц», «Что входит» |
| `fon-koridor.jpg` | «Сколько стоит» |
| `final-desktop.jpg`, `final-mobile.jpg` | последний экран: стойка консьержа |

Розовых фонов не ставить (Артём, 04.11.2026).

Предметы (04.11.2026): один лист на зелёном хромакее, разрезан на PNG
с прозрачным фоном — `o-kino` (шаг «Кинотерапия»), `o-chashka` (подарок), `o-pismo` (вопросы), `o-klyuchi`
(пока не стоит, для «Первых трёх месяцев»).

«Каждый месяц вы получаете» (05.11.2026) — раскрытый блокнот на кольцах.
Исходник: картинка Артёма на хромакее, разрезана в `bloknot/`: `l`, `r` —
страницы с обложкой (border-image), `spine-top`, `spine-strip`, `spine-bot`,
`ring` — корешок и кольца. Телефон: блокнот на пружине сверху (вторая
картинка Артёма), части `tel-top` (кольца, масштаб целиком), `tel-mid`
(середина листа, тянется), `tel-bot` (низ с уголками). Бумага на всех частях выровнена в один тон, иначе видны швы.
Предметы пунктов: `o-klyuchi`, `o-mikrofon`, `o-proektor`, `o-tetrad`,
`o-chasy`, `o-kino`, `o-pismo`.
