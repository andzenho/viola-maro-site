# Картинки оформления --theme barhat (красное с белым)

Сюда кладутся картинки для `--theme barhat`. Имена файлов строгие: сборщик
ищет именно их (список в `tema_barhat.py`, словарь `SLOTS`). Пока файла нет,
на его месте стоит фон из градиента, страница выглядит законченной.

| Файл | Что это | Размер |
|---|---|---|
| `hero-desktop.jpg` | Виола в сцене, горизонтальная: она справа, слева пустое место под текст | 2400×1400 |
| `hero-mobile.jpg` | Виола в сцене, вертикальная: она по центру | 1080×1600 |
| `lenta.png` | бледно-золотая лента на прозрачном фоне | от 1200 по ширине |
| `barhat.jpg` | красный шёлк для красных блоков | 2000×2000 |
| `mk.jpg` | зал со сценой, блок мастер-класса; главное справа | 1600×1200 |
| `final.jpg` | приоткрытая дверь со светом, последний призыв | 2400×1200 |

Если сцены с Виолой нет, на первом экране стоит её настоящий снимок
(`source/assets/viola-cutout.png`) на красном фоне.
