# Страница-заявка для Кабинета: violamaro.ru/kabinet

Отдельная страница для подписчиков закрытого канала Виолы. Человек оставляет
заявку и попадает в чат с менеджером. Оплаты нет; цена Кабинета на странице
не пишется нигде, её называет менеджер. С основного сайта на страницу
не ссылаемся, индексация запрещена.

Собирает `kabinet.py` (в корне репозитория), после основного сайта:

```sh
python3 build.py --theme barhat --noindex
python3 kabinet.py
```

## Что менять без правки вёрстки

Словарь `CONFIG` в начале `kabinet.py`:

| Ключ | Что это |
|---|---|
| `PRICE_SELF`, `PRICE_VIOLA` | цены сайта в карточках тарифов |
| `PRICE_DEADLINE` | до какого числа менеджер держит цену Кабинета |
| `MANAGER_TG` | ник менеджера в текстах |
| `MANAGER_CHAT_URL` | куда уводим после заявки (ссылка `t.me/m/…` с готовым сообщением) |
| `SEATS_LEFT` | сколько мест осталось; пусто — счётчика нет |
| `METRIKA_ID` | номер счётчика Яндекс Метрики; пусто — цели не уходят |
| `FORM_KIND` | `заявка` или `кабинет`, см. ниже |

Состав тарифов, недели и бонусы берутся из `build.py`; тексты остальных
блоков стоят в `kabinet.py` дословно по ТЗ.

## Отзывы

Скрины кладутся в `kabinet/reviews/` (jpg, png, webp). Пока папка пуста,
блока на странице нет. Порядок — по имени файла.

## Куда уходит заявка

Адрес приёмника и общий секрет берутся из `build-assets/site.js`.

- `FORM_KIND = "заявка"` (сейчас). Заявку принимает уже развёрнутый скрипт:
  строка ложится в общий лист «Заявки на продукт», в колонке «Тариф» стоит
  «Кабинет: …», в «Готовность» — приоритет, что важнее и когда готовы,
  в «Метка» — `kabinet`.
- `FORM_KIND = "кабинет"`. Свой лист «Кабинет» с приоритетом, статусом
  (выпадающий список), обновлением дублей за сутки и уведомлением в Telegram;
  копия по-прежнему ложится в общий лист. Нужна версия скрипта
  `2026-10-14 kabinet` (`integrations/google-sheets/`) и два свойства скрипта:
  `KABINET_BOT_TOKEN`, `KABINET_CHAT_ID`. Ставить только после развёртывания:
  прежняя версия такую форму не знает и заявку не запишет.

## Цели Метрики

`kabinet_cta` (клик по «Оставить заявку»), `kabinet_submit` (заявка
отправлена), `kabinet_tg` (переход в чат, сам или по кнопке).
