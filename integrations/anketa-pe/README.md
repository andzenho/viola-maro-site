# Анкета участниц → отдельная Google Таблица

Приёмник для страницы `violamaro.ru/anketa/` (`miniapps/anketa/`).
Таблица: «Анкета участниц Прикладной эмпатии», лист «Ответы».
Это отдельная таблица и отдельный скрипт; таблицу заявок
(`integrations/google-sheets/`) они не трогают.

- `Code.gs` — сам скрипт: принимает анкету и дописывает одну строку.
- `appsscript.json` — настройки проекта (нужен только при заливке через `clasp`).

## Как развернуть

Таблица принадлежит аккаунту `ilyakras.work@gmail.com`. `clasp` на рабочем
Маке вошёл под другим аккаунтом, и создать скрипт в этой таблице он не может,
поэтому разворачивает владелец таблицы, руками. Это один раз, минуты три.

1. Откройте таблицу → меню **Расширения** → **Apps Script**.
2. В открывшемся редакторе удалите всё, что есть в файле `Код.gs`,
   и вставьте содержимое `Code.gs` целиком. Нажмите «Сохранить».
3. Справа вверху **Развернуть** → **Новое развёртывание** → шестерёнка →
   **Веб-приложение**.
   - «Выполнять от имени»: **от моего имени**.
   - «У кого есть доступ»: **Все**.
4. Нажмите **Развернуть**. Google попросит разрешить скрипту доступ
   к таблице: «Проверить разрешения» → выберите свой аккаунт → «Разрешить».
5. Скопируйте **URL веб-приложения** (кончается на `/exec`) и вставьте
   в `miniapps/anketa/index.html`, в `CONFIG.sheetUrl`.

Проверка: откройте этот адрес в браузере. В ответе должно быть
`"note":"Приёмник анкеты участниц жив"` и число анкет.

## Если меняете скрипт потом

**Развернуть** → **Управление развёртываниями** → карандаш → «Версия: Новая
версия» → **Развернуть**. Адрес при этом не меняется. Новое развёртывание
вместо правки старого даст другой адрес, и анкеты перестанут доходить.

## Что скрипт проверяет

- Строку без ника или без согласия на обработку данных не записывает
  и возвращает ошибку.
- Заполненное поле-приманку считает ботом: отвечает «ок» и ничего не пишет.
- Текст, начинающийся с `=`, `+`, `-` или `@`, записывает с апострофом,
  чтобы он не стал формулой (ник `@anna` иначе дал бы ошибку в ячейке).
- Пишет 42 значения в колонки A–AP. Колонку AQ «Статус бонусов» не трогает.
