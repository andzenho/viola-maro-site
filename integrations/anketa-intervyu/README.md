# Анкета для интервью → отдельная Google Таблица

Страница `violamaro.ru/intervyu/` (`miniapps/intervyu/`), приёмник `Code.gs`.
Лист «Ответы» скрипт заводит сам, с шапкой.

## Как развернуть (один раз, минуты три)

1. Создайте пустую Google Таблицу «Анкета для интервью».
2. **Расширения** → **Apps Script** → удалите всё в `Код.gs`, вставьте `Code.gs` целиком, «Сохранить».
3. **Развернуть** → **Новое развёртывание** → шестерёнка → **Веб-приложение**.
   «Выполнять от имени»: **от моего имени**. «У кого есть доступ»: **Все**.
4. **Развернуть**, разрешить доступ к таблице.
5. URL веб-приложения (кончается на `/exec`) вписать в `miniapps/intervyu/index.html`, `CONFIG.sheetUrl`.

Проверка: открыть адрес `/exec` в браузере, в ответе «Приёмник анкеты для интервью жив».

## Как читать ответы

- **Сегмент**, колонка «Где сейчас»: «тяжело, сил нет» минус, «справляюсь, хочу прийти в норму» ноль, «жизнь налажена, хочу расти» единица.
- **ЦА**: женщина 45–54, смотрит больше года, силы забирают мама, муж или «живу для других». Второй сегмент: 35–44, партнёр.
- **Деньги**: от 30 тысяч кандидат на «Прикладную Эмпатию», от 70 тысяч на мастер-группу.
- **Кого звать**: только «Интервью: Да». Половина из смотрящих меньше полугода, половина из давних, кто ничего не покупал.
- **Бонусы** только тем, кто согласился на интервью: аудиопрактика по теме из «Что забирает силы», запись второй лекции «Прикладной Эмпатии», первыми узнают о новой программе и лучшая цена. Колонка «Статус» для отметок команды.
