# Анкета участниц

Страница `violamaro.ru/anketa/` (`miniapps/anketa/`) пишет в таблицу «Заявки | Виола Маро», лист «Кастдев», с пометкой «Анкета участниц» в колонке «Откуда». Приёмник: `integrations/google-sheets/Скрипт-таблицы-целиком.gs`, функция `saveAnketaPe_`, развёртывание анкеты для интервью.

Отдельная таблица и отдельный скрипт, задуманные раньше, не используются (решение от 02.11.2026).
