# integration-update

Изменения подготовлены для ветки `integration-update`.

- актуальный `build.py` перенесён из `andzenho/Viola-Maro`;
- мини-апп «Тест эмпата» находится в `miniapps/test/index.html`;
- мини-апп «Колесо эмпата» находится в `miniapps/koleso/index.html`;
- GitHub Pages публикует их как `/test/` и `/koleso/`;
- ссылки внутри мини-аппов переведены на тестовый домен `pre.viola-maro.ru`;
- внутренняя форма предзаписи после «Прикладной эмпатии» больше не открывается;
- CTA теперь `Написать Артёму` и ведёт в отдельную Telegram Business-ссылку каждого теста;
- перед открытием Telegram мини-апп ждёт подтверждение Apps Script;
- нажатие отправляется как `type: "contact"`;
- Apps Script пишет нажатия в `Предзапись с теста` и не создаёт повторную строку для того же Telegram ID + теста;
- имя листа стартов исправлено на `Старт теста`.

Безопасная публикация:

- push в `integration-update` не публикует сайт и не влияет на работающие страницы;
- GitHub Pages запускается только после слияния проверенных изменений в `main`;
- текущие ссылки SaleBot на старые мини-аппы менять только после проверки новой публикации;
- перед слиянием сохранить текущий `main` отдельной резервной веткой.

Актуальная копия Apps Script также лежит в `integrations/google-sheets/Скрипт-таблицы-целиком.gs`. Тот же код передаётся отдельным файлом `Code_full_ready.gs`. Его нужно перенести в редактор Apps Script и обновить существующее веб-развёртывание новой версией. Если обновлять существующее развёртывание, URL `/exec` останется тем же.
