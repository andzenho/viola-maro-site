# Картинки оформления --theme barhat (чёрное с золотом)

Сюда кладутся картинки для `--theme barhat`. Имена файлов строгие: сборщик
ищет именно их (список в `tema_barhat.py`, словарь `SLOTS`). Пока файла нет,
на его месте стоит фон из градиента, страница выглядит законченной.

| Файл | Что это | Размер |
|---|---|---|
| `fon.jpg` | тёмный интерьер или сцена без людей: встаёт за настоящим снимком Виолы на первом экране | от 2000 по ширине |
| `hero-desktop.jpg` | готовая сцена с Виолой, горизонтальная: она справа, слева тёмное место под текст | 2400×1400 |
| `hero-mobile.jpg` | готовая сцена с Виолой, вертикальная: она по центру | 1080×1600 |
| `lenta.png` | лента или другая деталь на прозрачном фоне | от 1200 по ширине |
| `barhat.jpg` | тёмная фактура для карточек со светом | 2000×2000 |
| `mk.jpg` | зал со сценой, блок мастер-класса; главное справа | 1600×1200 |
| `final.jpg` | последний призыв | 2400×1200 |

Если готовой сцены нет, на первом экране стоит настоящий снимок Виолы
(`source/assets/viola-cutout.png`): внизу он растворяется в чёрном.
